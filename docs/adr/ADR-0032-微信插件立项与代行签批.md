# ADR-0032 微信插件立项与代行签批（WBS 18 OPEN-06 裁决）

- **状态**：Accepted（项目发起人 2026-11-21 指令「代行签批全量实现」；代行法务 + 产品角色，**非实名会签**，依 `17` §1 P0 先例；平台条款风险由发起人承担）
- **日期**：2026-11-21
- **决策者**：项目发起人（用户）在「先合规评审 / 暂缓 / 代行签批全量实现」三选项中明确选择全量实现
- **关联**：ADR-0018（微信能力隔离为可选插件）、ADR-0014（goja 引擎）、`03` FR-SRC-05、`09` §提权助手、`11` §7、`13`、`14` WBS 18 / R-13 / OPEN-06、`16`

## 背景

ADR-0018 已决策「若做微信能力，则单独分发、默认不安装、提权隔离、法务逐条审阅
平台条款」，但把「是否立项」（OPEN-06）留给法务 + 产品在 P3 启动前决定。
该项与 R-13（高）绑定，缓解措施为独立合规评审，应急为「法务否决即整体移除」。
截至 2026-11-21 未立项、代码零实现。发起人本次明确指令代行签批并全量实现，
构成 OPEN-06 的立项决议。

**技术勘察结论**：现有 goja 插件引擎（`Type` 恒为 resolver、`fs/env/subprocess`
加载期拒绝、ES5.1 软隔离）**不能承载**微信能力主体——视频号需 goproxy MITM、
私有加解密、流量嗅探，必须原生 Go + 独立进程。可复用的只有规则包治理机制
（Ed25519 签名、静态扫描、目录指纹热更新）。

## 决策

1. **立项并全量实现 WBS 18**，按 ADR-0018 已定的隔离边界落地：
   - MITM 转发本体（goproxy，Go 库）跑在**独立插件进程**内，非主进程 sidecar；
   - 提权助手为**独立二进制 / 独立权限**，仅承载 4 项系统级操作（装/卸根 CA、
     改系统代理、注入 JS、热更逆向规则包），本地 IPC + 每次显式用户授权；
   - 规则包独立更新通道 + Ed25519 签名校验（复用 `internal/plugin` 治理模式）；
   - 一键卸载清理（CA、代理、注入脚本、进程）并验证无残留。
2. **默认不安装、不随主包分发**：主包 `/capabilities` 默认报 `unavailable`，
   主功能列表不列该能力；独立安装包 + 单独插件页面声明「需用户自行授权、
   遵守平台条款」。桌面端限定，移动端禁用。
3. **合规红线不因代行签批而放宽**：不碰 DRM（Widevine/FairPlay/PlayReady）、
   不提供会员内容绕过、仅下载「用户有权保存的内容」、不内置账号共享、
   不随主包内置嗅探。代行签批仅就 OPEN-06 立项与平台条款风险接受作出裁决，
   不改变 ADR-0018 的技术隔离边界。
4. **两层交付**：① 低风险层——公众号公开 HTML 解析（与 lux 站点解析同性质，
   可本地单测）；② 高风险层——视频号 MITM + 私有加解密，需真实微信 PC 客户端
   与逆向规则，CI 不可触达。
5. **风险承担如实记档**：R-13 由「高」维持，处置从「法务否决即移除」更新为
   「发起人代行签批接受平台条款风险，独立合规评审仍建议补做」；
   **本 ADR 为非实名代行，不得表述为法务实名签字通过**。若将来平台条款变化或
   法务实名否决，按 ADR-0018 应急措施整体移除且不影响主程序。
6. **关闭 OPEN-06**：结论为「立项，代行签批，全量实现」，不再列为未决事项。

## 备选方案

- **先合规评审再做 / 整体暂缓**（否决）：发起人明确指令全量实现，且 ADR-0018
  的隔离边界本身即为合规缓解；等待会阻塞 P3 WBS 18。
- **复用 goja 引擎**（否决）：类型/能力/隔离级别三处不符（见背景）。
- **随主包分发**（否决）：违反 ADR-0018 与 NG-06，风险扩散到主程序上架与签名。

## 后果

正面：解锁公众号/视频号内容源；独立分发不污染主包合规面；隔离架构清晰。
负面：MITM + 逆向规则高频失效（持续维护）；平台条款与个人信息合规风险（R-13 高）；
独立安装包签名/公证成本；桌面多平台矩阵。非实名代行签批的治理瑕疵需在
实名法务评审可用时补签。

## 合规与验证

- 离线可验证：公众号 HTML 解析单测、插件 manifest 能力拒绝、`/capabilities`
  默认 unavailable、提权助手 IPC 接口契约、规则包 Ed25519 验签、卸载清理逻辑。
- 真实环境（**NOT_EXECUTED**，需微信 PC 客户端 + 真实网络 + 逆向规则）：视频号
  MITM 连通、加解密、CA 安装/卸载、代理恢复；未执行前不得宣称该能力可用。
- 合规材料：平台条款逐条审阅清单模板随包归档，标注「代行签批、待实名复核」。
